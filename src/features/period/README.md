# 生理期模块

`PeriodPage` 组合首页、月历、周期摘要、每日记录。继续使用应用底部导航、Yozai 字体与公共 Modal，不改动待办逻辑和数据库。

## 存储与日期

复用现有 Dexie，模块数据库 `cozy-days-period` 的 `state` 表保存经期、按日期索引的日记和设置。不迁移、清空或关联待办数据库。预测为纯派生结果，不保存为真实经期。旧版记录中已停用字段作为不透明附加数据保留，编辑和恢复时原样传递；不迁移或主动清除，保存比较仍使用完整原始形状。新版空记录仅包含现有业务字段。写入串行执行；读取/写入错误显式显示并支持重试。写入前即时更新 UI，失败保留当前会话数据等待重试。

日期保存为 `YYYY-MM-DD`，纯日期运算通过 UTC 整日整数完成，不把本地午夜转换为 ISO 日期。今天取设备当地日历，每 30 秒及窗口恢复焦点时刷新。

历史记录不允许未来、倒序、重叠；无结束日期代表仍在进行，仅标记至今天。结束日期包含当日。日记中的流量不自动创建、更改或结束经期。

每日记录第一行“生理期来了”的是/否只由真实区间派生，不保存第二份布尔状态。选择“否”隐藏流量选项，但保留已存流量、症状、心情与未知附加字段；开关仅修改 `periods`。未来日期开关禁用。

- 今天从否改是创建今天开始的进行中区间；所有相邻区间统一分别保留，不隐式合并。今天从是改否将对应区间结束于昨天，单日区间则移除。
- 历史日期从是改否先弹窗列出所选日期至原区间结束（进行中则至今天）的受影响范围。确认后截断至所选日期前一天；若选择区间开始日期，则移除该区间。取消不改记录。
- 历史日期从否改是，若存在后续真实区间，或任一真实区间与近90天（今天及之前89天，含首尾）相交，立即要求结束日期；仅在两项均不满足时创建所选日期至今天的进行中区间。今天的开关不适用90天限制。拒绝未来、倒序、无效与重叠日期，保护已有区间。相邻记录分别保留。
- 截断弹窗保存打开时的本地“今天”及显示范围。确认前若本地日期改变，直接拒绝且不调用持久化更新；重新推导的起止范围必须与原显示相同。关闭并重新选择后才能确认新的范围。

`periodToggle.ts` 提供纯函数 `actualPeriod` 与 `planPeriodToggle`；模型返回确认截断、必须结束日期、可应用结果或错误，页面通过现有 `usePeriod.update` 写入，不改变数据库或恢复协议。

## 统计规则

- 周期：按开始日期排序，最近最多 6 个相邻起始间隔的算术平均，四舍五入。
- 经期：最近最多 6 次已结束记录的含首尾天数平均，四舍五入。
- 历史不足时分别使用用户设置的周期/经期长度，默认 28/5 天；UI 标注“设定”与“平均”。默认值不是用户数据。
- 下次开始 = 最近开始 + 周期长度。只估算下一次；过期显示超期天数，不虚构多个周期。
- 排卵暂估下次开始前 14 天；易孕期暂估前 5 天至后 1 天。均明确标注预测，不能用于避孕和医疗诊断。

## 素材接入

修改 `PeriodArt.tsx` 中 `art` 配置：`header` 为顶部白猫/黑猫主题插画，`note` 为记录区猫咪与暖饮。独立透明资源使用相对 Vite BASE_URL 路径，保留组件预留尺寸。当前 CSS 猫咪为可运行占位；月亮、星星、爱心、胶带也可后续拆成透明素材。不可将完整日历、卡片或文字导出成背景图片。装饰始终 aria-hidden、不可点击，不包含业务信息。

## 限制

仅本地存储，无云同步、导出或系统推送通知。浏览器清除本站数据会丢失记录；不同预览源站数据互相独立。尚未在 Android 真机验证软键盘与手势安全区。多标签页同时修改不做冲突合并。周期不规律等情况可能影响预测准确性。

周期推算不是医疗诊断。
