# 代码审查与修复（2026-10-23）

审查范围：应用入口和导航、三个模块、待办表单/卡片/撤销、分类与 Dexie 仓储、日期处理、字体注册与加载、弹窗和共享组件、资源引用、Vite/Capacitor 配置及 GitHub 工作流。此记录不代表 Android 真机验收或安全认证。

## 已修复

- 日期校验比较本地日历字段，避免 UTC+14 将本地中午转换成前一天而误拒有效日期；表单日历入口使用相同校验，拒绝 2 月 30 日等日期。
- 当前字体启动加载失败后，允许重新点击同一字体重试。
- 字体切换使用同步互斥标记并禁用加载中的选项，阻止并发切换；多字重全部加载成功后才注册，避免部分失败后留下重复字体实例。
- 长按仅响应主指针，忽略其他指针的移动/取消，开始新手势前清理旧计时器，卸载时清理计时器。
- 导航禁用文本选择及原生触摸呼出，菜单打开时聚焦设置入口，导航的可访问名称与可见名称一致。
- 首次提示显示时记录已读，5 秒后自动隐藏，避免刷新反复显示。

## 验证

- Web、Pages 构建通过。
- audit-regressions、font-switcher、todo 三组共 16 项测试通过，包含日期边界、字体失败重试、导航及待办保存/撤销/刷新保留。
- 未运行全量 E2E，未修改用户的 README.md 与 tests/swipe.spec.ts。

## 现有局限

- 生理期、纪念日仍为占位入口，没有记录、计算和提醒逻辑。
- Android 硬件返回键尚未接入原生 App 插件；当前菜单关闭支持外部点击与键盘 Escape/Backspace，不能据此宣称已支持硬件返回。
- 本轮未进行 Android 真机测试。字体随构建打包，首次在线 Preview 下载仍较大：Yozai 两字重约 14.67 MB、小赖约 11.83 MB、源泉约 7.54 MB；按需加载避免同时下载全部字体，但没有缩减字库。
- 离线运行验证指 Android 已打包资源，网页没有 Service Worker，不能保证首次离线打开在线 Preview。
