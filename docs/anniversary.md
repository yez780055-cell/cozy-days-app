# 纪念日模块

入口使用 App 已有「纪念日」底部导航，不新增路由或导航系统。继承全局悠哉字体、纸纹和主题，所有新样式以 `ann-` 限定在模块内部。

## 数据与日期

- 沿用 `little-days` Dexie 数据库；版本 4 仅增加 `anniversaries` 表，不改写待办与分类。仓库负责读写和字段验证，初始表为空，不自动保存示例数据。
- 记录包含名称、YYYY-MM-DD 本地日历日期、主题、备注、图标、年度重复、颜色、创建/更新时间，为以后提醒功能保留明确结构。
- 单次事件保留原日期；年度事件计算今天或下一次发生日期，不早于原始起始年。今天归入「即将到来」，避免年度事件同时进入已过去分类。
- 2 月 29 日在平年按 2 月 28 日纪念，闰年恢复为 2 月 29 日；表单中明确提示。周年数为截至今天已经完成的整年。
- 不通过 UTC 字符串转换保存/读取日期。天数使用日历年月日的数值序数相减，因此跨夏令时仍按日历天计数。设备恢复前台与每 30 秒刷新当天，防止长时间停留后倒计时过期。
- 周栏可选择日期、翻周；月视图可翻月、选择日期和查看该日事件。列表筛选为全库范围，不会因选择一个没有事件的日子隐藏其他收藏。

## 素材替换

`src/features/anniversary/artwork.ts` 集中管理顶部双猫、空状态双猫和闪光的语义别名，当前复用已有审核素材。卡片图标暂用字符/emoji，不是从参考图新裁剪的正式插画。素材 PR 合并后替换映射即可。`Asset` 自带离线 SVG 回退，素材缺失仍可使用全部功能。

## 验证与限制

运行 `npx playwright test --config playwright.anniversary.config.ts`（可设 `PLAYWRIGHT_CHANNEL=chrome`）。独立 5186 端口避免误用其他并行工作区的开发服务器。测试同时覆盖纪念日、现有待办和分类，浏览器上下文均独立，所有数据为测试合成数据。

运行 `npm run build`、`npm run build:pages`、`npm run test:pages` 验证类型检查与两种资源基础路径。真实截图由 Playwright 写入 `public/review/anniversary/`；静态验收入口 `/review/anniversary/`，来源提交记录在 `source.json`。

Android 原生软键盘、原生安全区、APK 和提醒推送未在此任务验证/实现。浏览器覆盖 360×740、393×852、430×932、缩短视口、滚动、按钮与导航的避让；悬浮新增按钮拥有底部独立留白，不遮挡卡片操作。新增弹层复用共享可视视口与焦点管理。
