# 生理期模块

`PeriodPage` 组合首页、月历、周期摘要、每日记录、提醒和小贴士。继续使用应用底部导航、Yozai 字体与公共 Modal / Checkbox，不改动待办逻辑和数据库。

## 存储与日期

复用现有 Dexie，模块数据库 `cozy-days-period` 的 `state` 表保存经期、按日期索引的日记、提醒和设置。不迁移、清空或关联待办数据库。预测为纯派生结果，不保存为真实经期。写入串行执行；读取/写入错误显式显示并支持重试。写入前即时更新 UI，失败保留当前会话数据等待重试。

日期保存为 `YYYY-MM-DD`，纯日期运算通过 UTC 整日整数完成，不把本地午夜转换为 ISO 日期。今天取设备当地日历，每 30 秒及窗口恢复焦点时刷新。

历史记录不允许未来、倒序、重叠；无结束日期代表仍在进行，仅标记至今天。结束日期包含当日。日记中的流量不自动创建、更改或结束经期。

## 统计规则

- 周期：按开始日期排序，最近最多 6 个相邻起始间隔的算术平均，四舍五入。
- 经期：最近最多 6 次已结束记录的含首尾天数平均，四舍五入。
- 历史不足时分别使用用户设置的周期/经期长度，默认 28/5 天；UI 标注“设定”与“平均”。默认值不是用户数据。
- 下次开始 = 最近开始 + 周期长度。只估算下一次；过期显示超期天数，不虚构多个周期。
- 排卵暂估下次开始前 14 天；易孕期暂估前 5 天至后 1 天。均明确标注预测，不能用于避孕和医疗诊断。

## 素材接入

修改 `PeriodArt.tsx` 中 `periodArt` 配置：`header` 为顶部白猫/黑猫主题插画，`note` 为记录区猫咪与暖饮，`tips` 为小贴士角落插画。独立透明资源使用相对 Vite BASE_URL 路径，保留组件预留尺寸。当前 CSS 猫咪为可运行占位；月亮、星星、爱心、胶带也可后续拆成透明素材。不可将完整日历、卡片或文字导出成背景图片。装饰始终 aria-hidden、不可点击，不包含业务信息。

## 验证

`npx playwright test --config playwright.period.config.ts`：周期和日期边界、录入/修改/删除、重叠拒绝、按日多选、提醒持久化、预测参数、待办数据隔离及 360×740 / 393×852 / 430×932 适配，同时复跑现有 todo.spec.ts。浏览器测试只使用独立上下文与合成数据。

`npm run build`、`npm run build:pages` 与仓库 PR 快速验证一致。五类截图由 `tests/period.spec.ts` 生成到 `public/review/period/evidence`，验收页为 `/review/period/`。

## 限制

仅本地存储，无云同步、导出或系统推送通知。提醒是页面内清单。浏览器清除本站数据会丢失记录；不同预览源站数据互相独立。尚未在 Android 真机验证软键盘与手势安全区。多标签页同时修改不做冲突合并。周期不规律等情况可能影响预测准确性。

健康照护文字参考 NHS：https://www.nhs.uk/symptoms/period-pain/；周期推算不是医疗诊断。
